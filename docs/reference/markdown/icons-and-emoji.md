
:lucide-rocket: :material-heart: :octicons-mark-github-16: :fontawesome-brands-github: :simple-bun: :tada:

| Set             | Shortcode                     | Frontmatter `icon`          |
| --------------- | ----------------------------- | --------------------------- |
| Lucide          | `:lucide-rocket:`             | `rocket` or `lucide/rocket` |
| Material Design | `:material-heart:`            | `material/heart`            |
| Octicons        | `:octicons-mark-github-16:`   | `octicons/mark-github-16`   |
| Font Awesome    | `:fontawesome-brands-github:` | `fontawesome/brands/github` |
| Simple Icons    | `:simple-bun:`                | `simple/bun`                |
| Emoji           | `:tada:`                      |                             |

Classes after an icon change its size and alignment: `:material-heart:{ .lg .middle }`, `.xl` for larger.

Icons are downloaded on the first build and embedded in the compiled binary. Licenses: Lucide (ISC), Material Design Icons (Apache-2.0), Octicons (MIT), Font Awesome Free (CC BY 4.0), Simple Icons (CC0), gemoji (MIT).
